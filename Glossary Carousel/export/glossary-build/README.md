# Fossilflation · Jargon Giraffe glossary (350)

Open `index.html` (redirects to `Glossary Build.dc.html`): light page with the animation (Deliverable 1) and the 3-slide carousel (Deliverable 2), both 1080×1350.
Serve over http (GitHub Pages works); opening from file:// can block the script loads. three.js loads from esm.sh, so an internet connection is needed.
